# Web Calculator

A responsive browser-based calculator built with **HTML, CSS, and JavaScript**. This project was created to practice DOM manipulation, event handling, responsive UI styling, and basic arithmetic logic.

## Features

- Addition, subtraction, multiplication, and division
- Percentage operation
- Decimal and double-zero input
- `AC` to clear the calculation
- `DEL` to remove the last character
- Responsive calculator interface
- Interactive button-based input

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Web_Calculator/
├── index.html

└── README.md
```

## How to Run

No installation or dependencies are required.

1. Clone or download the repository.
2. Open `index.html` in a modern web browser.
3. Use the calculator buttons to perform calculations.
